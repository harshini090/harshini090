## 🔧 What I'm Building Right Now

### ClaimSense — AI-Powered Insurance Claims Triage
`Next.js 14` `Tailwind CSS` `Python` `OpenAI API` `PostgreSQL`

Insurance adjusters spend 40+ minutes per claim on initial review. ClaimSense uses structured AI prompts to extract key facts from claim documents, flag inconsistencies, and generate preliminary assessments — reducing first-touch review time by an estimated 60%. Built with Next.js 14 App Router for server components and streaming UI, backed by a Python processing pipeline.

**Why it matters:** This isn't a ChatGPT wrapper. It's a domain-specific tool with structured output parsing, confidence scoring, and an audit trail that meets insurance compliance requirements.

### Private-Eye — Privacy-First Document Redaction at the Edge
`Rust` `WebAssembly` `Edge Computing` `Computer Vision`

Sensitive documents shouldn't leave your device for redaction. Private-Eye runs PII detection entirely in the browser using a Rust-compiled Wasm module — zero server round-trips, zero data exposure. Detects and redacts SSNs, account numbers, and addresses from uploaded PDFs with sub-second latency.

**Why it matters:** Enterprise privacy teams currently rely on cloud-based redaction tools that create the very data exposure risk they're trying to prevent. This flips the model entirely.
